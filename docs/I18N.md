# Internationalization (i18n)

## Current design (1.x)

All user-visible strings for **English** and **French** live in external files
**`locales/en.sh`** and **`locales/fr.sh`**, each defining a `declare_i18n_en` /
`declare_i18n_fr` function that sets the global message variables. The active
set is selected at runtime from `--lang` or, if unset, from locale env vars in
`detect_language()` order: `LC_ALL`, `LC_MESSAGES`, `LC_CTYPE`, then `LANG`.
Unsupported `--lang` values (`de`, path-like strings, …) are allowlisted away
before `load_i18n` builds a filename, so they fall back to English and
`parse_args` reports `MSG_ERROR_INVALID_LANG` rather than “locale files not found”.

### Locale resolution

`resolve_locales_dir()` locates the `locales/` directory in this order:

1. `TM_EXCLUSIONS_LOCALES_DIR` env var (escape hatch for tests / unusual installs —
   ignored when running as root to avoid sourcing an untrusted path).
2. `<script_dir>/locales/` (source-checkout layout).
3. `<script_dir>/../share/tm-exclusions/locales/` (installed layout).
4. `/usr/local/share`, `/opt/homebrew/share`, `/usr/share` `tm-exclusions/locales`
   (Homebrew / system install roots).

### Adding or changing strings

1. Add the key in **both** `locales/en.sh` (`declare_i18n_en`) and
   `locales/fr.sh` (`declare_i18n_fr`).
2. Run `make check` and spot-check `bash tm_exclusions.sh --lang fr --help`
   (and `en`).
3. Update `README.md` if user-facing docs quote fixed English text.

### Optional override

`TM_EXCLUSIONS_DEFAULT_CONF` overrides the built-in rules file only; it does not
change i18n. `TM_EXCLUSIONS_LOCALES_DIR` overrides the locale bundle directory
(non-root runs only).

## Archived 2.x layout (reference only)

The archived **2.x** layout also used **`locales/en.sh`** and **`locales/fr.sh`**
sourced by the main script. The external-file split is now implemented in 1.x.
